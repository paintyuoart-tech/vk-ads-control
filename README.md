# VK Ads Control — шаблон для нового владельца

Готовый дашборд рекламных проектов в стиле Liquid Glass. Архив очищен от
проектов, токенов, ссылок Asana, идентификаторов кабинетов и базы предыдущего
владельца.

## Быстрый старт

1. Распакуйте архив.
2. Откройте распакованную папку в Codex.
3. Откройте `START_HERE.md` и отправьте Codex указанный там запрос.

## Локальный запуск

```bash
npm install
npm run dev
```

Адрес: `http://localhost:3000`.

## База данных

Создайте новый проект Supabase и примените по порядку файлы из
`supabase/migrations`. Они создают таблицы, функции, индексы и RLS-политики.

## Секреты

Скопируйте `.env.example` в `.env.local` и заполняйте только ключами нового
владельца. Никогда не отправляйте `.env.local` в GitHub и не добавляйте секреты
в исходный код.

## Публикация

Codex создаст новый проект размещения из `.openai/hosting.json`. Файл намеренно
не содержит идентификатор сайта предыдущего владельца.
