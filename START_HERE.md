# Запуск настройки в Codex

Отправьте Codex этот запрос:

> Подготовь этот дашборд для моих рекламных проектов. Сначала проверь сборку и
> структуру базы. Затем помоги создать мой Supabase, применить миграции и
> настроить вход. После этого добавляй мои проекты по одному: название, рекламная
> система, идентификатор кабинета, цели, месячный бюджет и KPI. Токены храни
> только в `.env.local` и переменных хостинга. Не используй и не запрашивай
> данные предыдущего владельца. После настройки проверь синхронизацию каждого
> проекта и опубликуй сайт в моём аккаунте Cloudflare.

## Что подготовить

- аккаунт Supabase;
- аккаунт Cloudflare;
- токены VK Ads и/или Яндекс Директа;
- идентификаторы рекламных кабинетов;
- список проектов, бюджетов, целей и KPI;
- при необходимости ссылки Asana и Google-таблиц.

## Правила безопасности

- не вставлять токены в чат, если Codex может записать их сразу в локальный
  `.env.local`;
- не публиковать `.env.local`;
- не использовать общий Supabase или Cloudflare предыдущего владельца;
- после подключения проверить один проект, затем подключать остальные.
